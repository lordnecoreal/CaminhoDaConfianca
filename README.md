# 🚀 Caminho da Confiança — EY Brasil

> **Caminho da Confiança** é um minijogo interativo de alta performance desenvolvido sob medida para eventos corporativos e de inovação em colaboração com a **EY Brasil**. O projeto foi concebido para testar a agilidade estratégica e a tomada de decisões rápidas dos participantes frente a desafios do ecossistema empresarial moderno.

## 🎮 Sobre o Jogo

O jogo coloca o participante no centro de cenários corporativos reais onde cada segundo conta. O objetivo principal é classificar rapidamente diferentes situações empresariais arrastando o card ou tocando diretamente nas zonas laterais correspondentes:

* 🛡️ **Obstáculo / Insegurança** (Lado Esquerdo): Riscos cibernéticos, processos manuais obsoletos, vulnerabilidades de infraestrutura e barreiras culturais.
* 🚀 **Transformar / Crescer** (Lado Direito): Adoção de Inteligência Artificial, transição ESG, inovação aberta, governança robusta e arquitetura em nuvem.

O jogo conta com um sistema dinâmico de pontuação, combos por acertos consecutivos (como o super *Combo 15*), efeitos sonoros via Web Audio API e um **Ranking Oficial em tempo real**.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido de forma 100% nativa e otimizada, sem dependências pesadas de *bundlers*, garantindo leveza e carregamento instantâneo em totens interativos, tablets e smartphones:

* **HTML5 Canvas & DOM**: Motor gráfico em tempo real para renderização fluida dos cards com física de arraste.
* **TailwindCSS (via CDN)**: Estilização moderna, responsiva e adaptável.
* **JavaScript (ES6+)**: Lógica completa de jogo, gestão de estados, temporizadores e manipulação de armazenamento local (`localStorage`).
* **Web Audio API**: Geração nativa de efeitos sonoros e banda sonora (BGM) sem necessidade de ficheiros de áudio externos.

## ✨ Funcionalidades Principais

* **Modo Responsivo Universal**: Totalmente adaptado para computadores (com rato/drag-and-drop) e ecrãs táteis/telemóveis.
* **Sistema de Temas**: Alternância dinâmica entre **Modo Escuro** e **Modo Claro**.
* **Teclado Virtual Integrado**: Facilita o registo do nome no ranking em totens touch sem teclado físico.
* **Painel de Configuração do Operador**: Permite personalizar logótipos de patrocinadores, subtítulos, duração da partida e reiniciar o ranking de forma secreta.

## 🕹️ Como Jogar

1. No ecrã inicial, toca em **"Toque aqui para começar"** ou entra pelo menu principal.
2. Lê as regras rápidas e clica em **"Iniciar Desafio"**.
3. Um card com um desafio corporativo aparecerá no topo do ecrã.
4. **Como classificar:**
* **Arraste:** Clica/toca no card, arrasta-o para o lado esquerdo (Obstáculo) ou direito (Transformar) e solta.
* **Toque direto:** Podes também tocar diretamente nas zonas laterais de opção para classificar o card instantaneamente.


5. Acumula pontos, mantém o foco nos combos e tenta garantir um lugar no **Top 10 do Ranking Oficial**!

---

## ⚙️ Painel do Operador

O projeto possui um painel de controlo oculto ideal para administradores de eventos em totens:

* **Como aceder:** Clica e segura no canto superior esquerdo do ecrã (perto do logótipo) durante **3 segundos** (ou pressiona `Ctrl + Shift + C` no teclado).
* **O que podes configurar:**
* Nome e logótipo personalizado do patrocinador do evento.
* Subtítulo dinâmico dos cabeçalhos.
* Tempo de duração de cada partida (de 10 a 300 segundos).
* Ativação/desativação de efeitos sonoros.
* Restauração de padrões e limpeza do ranking.

## 💻 Instalação e Execução Local

Como o projeto é construído em tecnologias web puras, não precisas de compilação complexa (`npm install`). Basta seguir os passos:

1. Clona este repositório para a tua máquina:
```bash
git clone https://github.com/teu-utilizador/caminho-da-confianca.git

```


2. Entra na pasta do projeto:
```bash
cd caminho-da-confianca

```


3. Abre o ficheiro `index.html` diretamente no teu navegador web preferido, ou utiliza a extensão **Live Server** (no Visual Studio Code) para uma melhor experiência de desenvolvimento.
